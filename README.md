# AI Workload Placement — Exploration

**Core question:** Given an AI workload, where should it run — device, edge, or cloud —
and which model should it use to meet quality, privacy, latency, cost, energy, and
hardware requirements?

## Status
Week 1 — territory exploration. Not building a product yet — mapping the landscape,
running first experiments, and looking for a real, underserved gap.

## Why this territory
- 2017 Cambridge research: Raspberry Pi, networking, edge device control
- Current: cloud/infrastructure engineering + GenAI/agents work

## What's here (so far)
- [ ] Landscape notes (existing tools: RunAnywhere, AWS Greengrass, Azure IoT Edge, etc.)
- [ ] First local-vs-cloud benchmark
- [ ] Problem signal log

## What this is NOT
Not claiming to invent edge/cloud AI or model routing — looking for what's still
painful, manual, or underserved for developers.
